# ATOM engineering archive

Cold storage for the engineering knowledge base: records that are closed,
superseded or belong to a finished run. Nothing in here is read during the
tiered intake; every file is reachable by link from the hot document it came
from. Entry text moved unchanged; link targets were repointed for the new
locations, and links into a finished run's ledger land on the stub ledger,
which points one hop onward.
